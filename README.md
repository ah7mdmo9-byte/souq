# حسابات السوق

تطبيق بسيط لحسابات أيام السوق (الأربعاء، الخميس، الجمعة، السبت): منتجات، أسعار، بيع، باقي، ومكسب كل يوم وكل أسبوع.

## النشر على GitHub Pages
1. اعمل مستودع جديد على GitHub (مثلا `souq`).
2. ارفع كل الملفات اللي في الفولدر ده (`index.html` و`manifest.webmanifest` و`sw.js` و`icon-192.png` و`icon-512.png`).
3. ادخل على **Settings ← Pages**.
4. في **Branch** اختار `main` و`/ (root)` ثم **Save**.
5. بعد دقيقة هيظهر الرابط: `https://اسمك.github.io/souq/`

## تثبيته على الموبايل
افتح الرابط في Chrome، ثم القايمة (⋮) ← **Add to Home screen**.

## ملاحظة
البيانات بتتحفظ داخل متصفح الموبايل نفسه (localStorage)، فمش بتتنقل بين موبايلين.
